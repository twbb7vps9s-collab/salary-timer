薪金計時器 離線版安裝步驟

【Netlify Drop（最簡單）】
1. 打開 https://app.netlify.com/drop
2. 把整個「salary-timer」資料夾（解壓後）拖進去
3. 得到網址後，用手機打開

【GitHub Pages】
1. 新增 repository，上傳這些檔案到根目錄
2. Settings → Pages → 選 main 分支 / root
3. 用手機打開 https://你的名字.github.io/repo名/

【加到主畫面】
- iPhone：用 Safari 打開網址 → 分享鍵 → 加入主畫面
- Android：用 Chrome 打開網址 → ⋮ → 安裝應用程式

第一次要連網打開一次，之後完全離線也能用。
注意：需要 https 網址才能離線，直接開本機檔案不行。
更新頁面後，請把 sw.js 的 salary-timer-v1 改成 v2，手機才會更新。
